# TΔLE — Landing Page Oficial

Repositorio de la landing page estática para la presentación del proyecto final **TΔLE (Sinaloa 2026)**.

## 🚀 Contenido del Repositorio
* `index.html` - Página principal en HTML5 estático con CSS incrustado responsivo y diseño en modo oscuro basado en la identidad visual de TΔLE.

## 🎨 Identidad Visual Aplicada
* **Space Deep Purple:** `#23014B`
* **Rocket Gold:** `#F0A60D`
* **Tipografía:** Bahnschrift / Sans-serif estilizado
* **Isotipo / Emblema:** Logotipo horizontal TΔLE + cohete espacial

## 🌐 Publicar en GitHub Pages
1. Sube este repositorio a tu cuenta de GitHub.
2. Ve a **Settings** > **Pages**.
3. En **Source**, selecciona la rama `main` y guarda los cambios.
4. Tu sitio web quedará disponible en breve.
